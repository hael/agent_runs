# Maintainer rulings for @RUN@

Decisions taken during the run. They override the plan where they differ; the first time a
session applies a ruling, it records it in the plan where it belongs, so the reviewed diff
carries it. Add a ruling here, then `~/agent_runs/arun rulings @RUN@` (while it runs) or
`~/agent_runs/arun resume @RUN@` (after a stop).
